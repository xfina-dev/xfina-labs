Strategy

Pick how the portfolio is maintained. You can add several and compare them on the same data.

Buy and hold v1

Set weights once, never trade. Shows how far the portfolio drifts.

Calendar rebalance v1

Restore targets on a schedule: monthly, quarterly, half-yearly or annual.

Threshold rebalance v1

Trade only when an asset drifts past a band around its target.

Perpetual rebalance later

Cash-flow driven: buy underweights first, sell only when necessary, tax-aware.

Threshold settings

The two band types are different, so the choice is explicit.
